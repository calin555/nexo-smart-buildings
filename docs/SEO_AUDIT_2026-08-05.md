# Audit SEO on-page și tehnic — nexcore.ro

Data auditului: 5 august 2026  
Domeniu canonic: `https://www.nexcore.ro`

## Rezumat

Auditul a acoperit identitatea din header, imaginile, metadatele, structura semantică, datele structurate, regulile de indexare, sitemapul și paginile editoriale prioritare. Inventarul complet cu URL, title și meta description se generează din aceleași surse TypeScript folosite de aplicație:

```bash
npm run seo:audit
```

Comanda listează toate paginile publice indexabile, inclusiv paginile dinamice de soluții, servicii, resurse, ghiduri, blog, localități, documente legale și branduri.

## Probleme găsite și reparate

- Logo-ul compunea vizual `N3` cu `N3XO Smart Buildings`, rezultând `N3N3XO Smart Buildings`. Marcajul separat este acum un simbol SVG decorativ cu `aria-hidden`, iar denumirea vizibilă apare o singură dată.
- Canonical-urile și URL-urile Open Graph erau relative. Generatorul SEO produce acum URL-uri absolute.
- Fallback-ul de producție pentru domeniu era localhost. Fallback-ul este acum `https://www.nexcore.ro`, iar `metadataBase` folosește explicit domeniul canonic.
- Pagini publice statice importante nu aveau canonical, Open Graph și Twitter Card complete. Homepage, Kituri, Configurator, proiectele interactive și brandurile folosesc acum metadate complete.
- Brandurile dinamice nu aveau metadata proprie. Fiecare brand primește title, description, canonical, Open Graph și Twitter Card unice.
- `robots.txt` nu excludea explicit loginul și onboardingul. Aceste rute sunt acum blocate împreună cu admin, portal, API și callbackurile auth.
- Sitemapul nu includea configuratorul comercial și noua pagină locală Cluj. Ambele sunt incluse; rutele private rămân excluse.
- Schema globală conținea doar Organization și WebSite. A fost adăugat ProfessionalService, cu date de contact și arie de operare declarată prudent.
- Paginile statice fără breadcrumbs structurale au primit WebPage și BreadcrumbList.
- Hero-urile soluțiilor și imaginile kiturilor/proiectelor aveau alt gol deși transmiteau informație. Au primit alternative descriptive în limba română. Nu există `alt="Image"` în sursele aplicației.
- Paginile Case Smart și Automatizare KNX aveau conținut insuficient și numai două FAQ-uri. Acum includ exemple, costuri orientative, construcție nouă versus renovare, funcționare fără internet, etape, mentenanță, documentație și minimum șase FAQ-uri vizibile.
- Ghidul Wi-Fi/Matter/KNX nu avea comparație completă. Acum include tabel semantic pentru cost, stabilitate, control local, securitate, scalabilitate și mentenanță, plus recomandări pentru apartamente, case și hoteluri.

## Pagini și conținut adăugat

### `/automatizari-case-cluj`

- title: `Automatizări case și sisteme KNX în Cluj-Napoca | N3XO`
- description: `Automatizări pentru case în Cluj-Napoca: proiectare KNX, smart home, iluminat, climat, securitate, instalare, programare și mentenanță.`
- H1 unic, servicii, localități deservite, proces, costuri orientative și șase întrebări frecvente.
- Linkuri interne către Case Smart, Automatizare KNX, configurator și cerere de ofertă.
- Schema Service, BreadcrumbList și FAQPage.

### `/solutii/case-smart`

- Conținut distinct despre scene și funcții pe camere, buget, renovare, funcționare locală, livrabile și mentenanță.
- Șapte FAQ-uri vizibile și schema Service + FAQPage.

### `/solutii/automatizare-knx`

- Conținut distinct despre magistrală, actuatoare, ETS, cost, renovare, funcționare locală, documentație și intervenții ulterioare.
- Șapte FAQ-uri vizibile și schema Service + FAQPage.

### `/ghiduri/wifi-matter-sau-knx`

- Tabel comparativ semantic și recomandări separate pentru apartament, casă și hotel.
- Linkuri interne către soluțiile Case Smart, KNX, configurator și ofertă.
- Schema Article, BreadcrumbList și FAQPage.

## Date structurate

- `Organization` — global.
- `ProfessionalService` — global, cu Cluj-Napoca, România, telefon și email.
- `WebSite` — global.
- `WebPage` — pagini publice.
- `Service` — soluții, servicii și pagina locală Cluj.
- `BreadcrumbList` — pagini editoriale, branduri, proiecte, kituri și configurator.
- `FAQPage` — numai pe pagini unde întrebările și răspunsurile sunt randate vizibil.
- `Article` — ghiduri și articole de blog.

## Indexare

Indexabile: homepage, pagini pilon, soluții, servicii, kituri, configuratoare publice, proiecte, branduri, resurse, ghiduri, blog, pagini locale și documente legale publice. Lista exactă este produsă de `npm run seo:audit` și corespunde rutelor din `sitemap.xml`.

Neindexabile: `/admin/`, `/portal/`, `/api/`, `/auth/`, `/login` și `/onboarding`. Loginul și onboardingul au și metadata `noindex, nofollow`.

## Verificări automate adăugate

- canonical absolut, Open Graph, Twitter Card și index/follow;
- prezența rutelor prioritare și absența rutelor private din sitemap;
- regulile robots pentru admin, portal, API, auth, login și onboarding;
- unicitatea title-urilor și meta description-urilor pentru conținutul data-driven;
- minimum șase FAQ-uri pentru paginile prioritare;
- tabelul comparativ din ghid;
- alt-uri descriptive pentru imaginile soluțiilor;
- logo fără `N3N3XO`;
- verificări E2E pentru metadata, H1, schemas, robots și sitemap.
- crawl E2E exhaustiv pentru toate URL-urile din sitemap, disponibil separat cu `SEO_FULL_CRAWL_ENABLED=1`.

## Observații rămase

- Indexarea efectivă este controlată de motoarele de căutare; după deploy trebuie retrimis `https://www.nexcore.ro/sitemap.xml` în Google Search Console.
- Datele juridice și detaliile entității contractante trebuie revizuite de un specialist înainte de utilizare comercială definitivă.
- Scorurile și rezultatele din Search Console trebuie urmărite după recrawl; acest audit validează implementarea tehnică și conținutul din repository.
